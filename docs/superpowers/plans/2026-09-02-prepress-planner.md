# «Препресс-Планер» — План реализации

> **Для агентных исполнителей:** реализация ведётся по фазам через субагентов (subagent-driven development). Контракт каждого агента — в `agents/NN_*.md`; спека — `docs/superpowers/specs/2026-09-02-prepress-planner-design.md`. Исполнитель читает ОБА документа.

**Goal:** мультиплатформенное (iOS/Windows/macOS/Linux) приложение препресс-планирования расходных материалов и ТЭО на Flutter с чистым Dart-доменом, серверной конвертацией закрытых форматов и подпиской с триалом 15 дней.

**Architecture:** монорепо: `packages/core` (чистый Dart-домен: геометрия, парсеры, лечение, массивы, расход+shape, технологичность, экономика/ТЭО, отчёты) → `app/` (Flutter UI, Ф3) → `services/converter`, `services/license` (FastAPI, Ф4). Легаси `cam_pipeline/`/`cam_material/` — эталон порта (в git не входят).

**Tech Stack:** Dart 3.13 (только stdlib — pub.dev недоступен), Flutter (Ф3), Python 3.12 + FastAPI (сервисы), Shapely/Python — только для генерации золотых эталонов.

**Spec:** `docs/superpowers/specs/2026-09-02-prepress-planner-design.md`

## Глобальные ограничения

- Только стандартная библиотека Dart; pub-зависимости запрещены.
- Запуск Dart: `C:\Users\user\Desktop\MyApp\vibe cam\.tools\dart-sdk\bin\dart.exe` (или `dart` из PATH). Тесты — `packages/core/test/*_test.dart` с `void main()` (см. `tool/test_utils.dart`); цикл по файлам.
- Нативные команды в pwsh: БЕЗ `2>&1` и БЕЗ пайпа вывода нативных команд в другие команды (песочница). Git: с `-c safe.directory='*'`.
- Русские тексты ошибок/UI. Числа: коорд. 4 знака, деньги 2 знака.
- В `packages/core` нет модулей УФ-маски и G-кода.

Порядок запуска субагентов (каждый = задача; ревью между задачами по two-stage review; TDD: сначала тесты, потом реализация):

- [ ] **T2 (агент 02, парсеры):** `lib/src/parser/*` + кросс-форматные тесты на fixtures. Зависит: модель (00). Параллельно с T1 не конфликтует (разные файлы), но использует `geom` только косвенно — можно параллельно.
- [ ] **T3 (агент 03, лечение):** после T1. `lib/src/healer/morphology.dart`, `lib/src/optimizer/topology.dart`.
- [ ] **T4 (агент 04, массивы):** после T1. `lib/src/optimizer/pattern_recognition.dart`, `array_generator.dart`. Может идти параллельно с T3 (разные файлы; оба от T1).

**Контрольная точка Ф1:** все `test/*_test.dart` зелёные; эталонная математика (§6 спеки) 1:1; коммит.

## Исполнение

Subagent-driven development: свежий субагент на задачу, двухстадийное ревью после каждой. Независимые задачи Ф1 (T1–T2, затем T3–T4) можно запускать параллельно (см. dispatching-parallel-agents), но коммиты — последовательные во избежание конфликтов; границы файлов не пересекаются.
