## 6. Пользовательские потоки

1. **Создание проекта.** «Проекты» → «Имя проекта» → «Создать»
   (`projects_screen.dart:42-55`). Без Pro-доступа и при непустом списке — шторка
   «Второй проект доступен в Pro (Free — 1 проект)» (`45-50`). Далее `save` +
   `load` + `onOpen` → переключение на «Геометрию» (`home_shell.dart:50-55`).
2. **Импорт.** Desktop — путь в поле или «Обзор» → «Импорт» (`geometry_screen.dart:222-235`);
   web — «Импорт файла» (браузерный диалог, `553-563`). `.ai/.cdr/.eps` уходят на
   сервер конвертации (`579`), остальные форматы разбираются локально.
3. **Лечение.** «Вылечить всё» → `healGeometry` → повторный анализ технологичности,
   список ошибок обновляется (`805-848`).
4. **Массив.** «Распознать массив»: мастер вылечивается отдельно, помечается слоем

9. **Отчёты.** «PDF ТЭО» / «XLSX» / «DXF мастера». Desktop пишет в каталог

## 11. Ограничения и известные дефекты

1. **Подпись «двойной клик — открыть», а работает один клик.** Текст подсказки в
   списке проектов `projects_screen.dart:91`, обработчик — одиночный `onTap`
   (`projects_screen.dart:93-96`).
2. **Проекты нельзя удалить/переименовать.** `ProjectStore` умеет только
   `save/load/listNames` (`project.dart:305-316`); UI-кнопок удаления нет.
3. **Одинаковое имя проекта перезаписывает файл.** Имя санитизируется и служит
   именем файла (`project.dart:300-303, 305-307`); проверки существования нет.
4. **ТЭО-параметры не персистентны.** Машина, оснастка, наценка, приладка, смена,
   цена смены и результат ТЭО живут только в состоянии экрана (`teo_screen.dart:56-73`)
   и не попадают в `Project` (`project.dart:66-79`) — после перезапуска сбрасываются.
5. **Отчёты не используют параметры ТЭО пользователя.** PDF/XLSX строятся с машиной
   `PriceCatalog.defaults().machines.first`, рабочим временем и валютой из каталога
   (`reports_screen.dart:46, 64-66`); из пользовательских данных учитывается только
   выбранный материал (`reports_screen.dart:29-37, 193-195`). Результат
   «Чувствительности» в отчёты не попадает (`teo_screen.dart:351, 432-457`).
6. **«DXF мастера» требует `healedPaths`, а не слоя MASTER.** Если массив распознан
   без предварительного «Вылечить всё», `healedPaths` пуст и кнопка неактивна
   (`reports_screen.dart:170-171`, `geometry_screen.dart:1058`), хотя мастер есть в
   `pattern.masterPaths` (`geometry_screen.dart:1037-1051`).
7. **Комментарий про «кнопку-шестерёнку» адреса конвертера расходится с кодом:**
   адрес в UI не редактируется, есть только «Запустить сервер» / «Проверить сервер»
   (`geometry_screen.dart:125` против `734-762`).
8. **Экран «Проекты» не пишет в журнал и не имеет плейсхолдера** для пустого списка
   (только заголовок и поле ввода) — `projects_screen.dart:59-99`.
9. **ТЭО не пишет в журнал** (файл не использует `AppLog`); операции с материалами
   подтверждаются только `SnackBar` (`teo_screen.dart:459-464`).
10. **Раскрой: вариант визуально выделяется, но в расчёт попадает только после
    «Применить»** — это осознанное поведение, но пользователю нужно нажать кнопку
    (`layout_screen.dart:47-49, 224-257`).
11. **Пустой список Z молча ничего не делает в UI** — только запись в журнал
    (`layout_screen.dart:299-302`).
12. **Квота Free считается по числу уже сохранённых проектов, а не по аккаунту**
    (`projects_screen.dart:45-50`) — это локальная защита, обходится удалением или
    переименованием файлов проекта. Гейтинг вообще клиентский: `entitlement.json` —
    обычный редактируемый файл (`entitlement_store.dart:15-17`; см. `SECURITY.md`,
    раздел 2, «Лицензирование — клиентская заглушка»).
