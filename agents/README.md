# agents/ — контракты субагентов «Препресс-Планер»

Каталог содержит **исторические контракты субагентов** (00–14), по которым
строились модули MVP (чистый Dart-домен в `packages/core`, Flutter-приложение,
сервисы конвертации и лицензирования). Контракты описывают, что должен был
построить каждый агент; они **не переписывались под текущий код**, а лишь
помечены статусом актуальности на 2026-09-07 (HEAD `448dcba`, ветка `master`)
в блоке сразу после заголовка. Тело контракта — история исполнения.
