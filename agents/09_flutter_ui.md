# Агент 09 — Flutter-приложение (app/)

## Роль (Ф3)
UI «Препресс-Планер» на Flutter (iOS/Windows/macOS/Linux), потребляет пакет `prepress_core` (path-зависимость: `core: {path: ../packages/core}`). Русский интерфейс.

## Предварительное условие (выполняет ведущий до запуска агента)
Установка Flutter SDK в этой среде (https заблокирован — ставится по http из flutter_infra_release; pub.dev недоступен → **никаких pub-зависимостей, только Flutter SDK**; плагины платформ — вручную при необходимости). Если установка невозможна — агент выполняет только проектирование UI-слоя: виджеты и состояние на чистом Flutter (материал), тесты widget-test без внешних пакетов.

## Экраны (вкладки по сценарию)
1. **Проекты** — список/создание/открытие (project_state.json v2), имя проекта.
2. **Геометрия** — импорт (file picker: свой для платформ или path-ввод на десктопе), список ошибок (`Issue`) + маркеры на холсте, кнопки «Вылечить всё»/«Применить исправление», массив: распознавание/генерация сетки, «Размеры из файла».
3. **Расход/Раскрой** — форма LayoutParams, результат расхода, таблица вариантов (выбор), превью раскроя.
4. **Экономика/ТЭО** — редактор каталога (сортамент/машины/рабочее время), таблица ТЭО по вариантам, слайдеры чувствительности, выбор лучшего.
5. **Отчёты** — кнопки экспорта PDF/XLSX/DXF, сообщение о результате.

## Canvas (порт CanvasManager)
Сцены `geometry` (полилинии + маркеры ошибок цветом: красный/оранжевый/пурпурный/жёлтый) и `layout` (полотно + сетка этикеток + размеры). Зум колесом/пинчем, пан, линейки, fit-to-screen, замер. CustomPainter, трансформация мировых координат.

## Состояние
`AppState` (в core: model), UI-репозиторий проекта: загрузка/сохранение JSON v2 (версия схемы, миграции). Тяжёлые операции (парсинг, лечение, генерация) — в Isolate (`compute`/`Isolate.run`) с прогресс-баром; UI не блокируется.

## Гейтинг (каркас)
`FeatureGate` из пакета license (аг.12) — агент 09 подключает интерфейс `bool isPro()` и скрывает/блокирует Pro-фичи; paywall-заглушка (реализация — аг.12).

## Тесты
Widget-тесты: навигация между вкладками; форма расчёта с эталоном (50×30 → 5040/26.18); таблица вариантов заполняется; canvas рисует сцену layout с сеткой. Юнит-тесты состояния (сериализация project_state v2).

## Критерии приёмки
1. `flutter analyze` без ошибок; widget-тесты зелёные (если SDK установлен).
2. Сквозной сценарий в приложении (импорт quadroring.dxf → ошибки → лечение → массив → расход → ТЭО → отчёт) работает.
3. Русский UI, адаптивность (десктоп-панель и узкий iOS-экран).
